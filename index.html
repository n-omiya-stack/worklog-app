Google Apps Script (GAS) 用コード例を表示

Googleスプレッドシートの「拡張機能」>「Apps Script」に以下のコードを貼り付けて、「Webアプリ」としてデプロイ（アクセス許可: 全員）してください。

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);

  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["日付", "名前", "区分", "出勤", "退勤", "休憩時間", "実働時間", "残業時間", "メモ"]);
  }

  sheet.appendRow([
    data.date,
    data.employeeName || '未指定',
    data.type,
    data.clockIn,
    data.clockOut,
    data.breakMinutes + '分',
    data.workHours + '時間',
    data.overtimeHours + '時間',
    data.note || ''
  ]);

  return ContentService.createTextOutput(JSON.stringify({result: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

スプレッドシートデータ出力オプション

集計データをGoogleスプレッドシートやExcel、その他の勤怠システムに取り込む形式を選択して出力できます。

スプレッドシート直接貼り付け (TSVコピー)

クリップボードにコピー後、スプレッドシートのセル(A1など)でCtrl+V(Cmd+V)を押すだけで綺麗に入力されます。

CSVファイルダウンロード (.csv)

Excelやスプレッドシートの「ファイル」→「インポート」から読み込める標準形式で保存します。

選択中の対象データを一括GAS送信

設定されているGAS Web App URLへ、表示中のデータを一括して送信します。
